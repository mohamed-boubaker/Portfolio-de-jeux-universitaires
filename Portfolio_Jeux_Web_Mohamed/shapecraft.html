ShapeCraft

Une mini simulation d’usine : relie une mine au centre de livraison, transforme les formes et lance la production.

Projet original : Java · SwingVersion web : HTML · CSS · JavaScript
Mine à gauche · Livraison à droiteObjectif : livrer 5 triangles bleus

Construis une chaîne ou clique sur « Exemple de chaîne ».

Ta petite usine ⚙️

0Livraisons
0Cycles

La mine verte crée des carrés gris. Les tapis déplacent les objets. Le rotateur transforme un carré en triangle ; le peintre le colore en bleu. Le Hub violet accepte les triangles bleus.

  • Sélectionne un outil puis clique sur une case.
  • Les machines de transformation font avancer les objets vers la droite.
  • Teste le bouton Exemple de chaîne si tu ne sais pas commencer.

Transparence : cette version jouable est une adaptation web simplifiée du projet universitaire d’origine. Le projet d’origine et cette démonstration sont distincts. L’adaptation en HTML, CSS et JavaScript a été réalisée avec l’aide de ChatGPT (OpenAI) ; elle ne prétend pas reproduire exactement le code C++, Java ou Python initial.
