Le même moteur.
Un nouveau terrain de jeu.

Réalisé en équipe pendant ma Licence 2 Informatique, Géométrie Shark utilise C++ et SDL2 pour gérer les déplacements, les collisions et les niveaux. Cette version compile le code C++ en WebAssembly et reprend les images et les trois niveaux du dépôt.

L’adaptation navigateur concerne le lancement, les commandes et la gestion des parties. Une musique électronique originale, « Shark Orbit », a été créée pour cette version. Elle démarre après le clic sur Jouer et se coupe avec le bouton Son ou la touche M.
