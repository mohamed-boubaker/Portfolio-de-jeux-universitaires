COMMENT JOUER

Les règles de ton projet.

Choisis une pièce et sa position dans Grille. Une pièce peut recouvrir les cibles, mais pas une autre brique. Tu peux échanger une pièce trop grande pour ton plateau.

Les contrôleurs Python, les requêtes et les templates proviennent du projet universitaire. Les boucles de génération et de placement ont été corrigées, et la grille rendue interactive. Les données SQL fournies dans le dépôt servent de point de départ.

L’application d’origine utilise PostgreSQL et le serveur pédagogique BDW. Ici, un adaptateur exécute le Python avec une base SQLite locale et traduit les requêtes nécessaires. La session est remise à zéro quand tu recharges la page.
