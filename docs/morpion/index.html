COMMENT JOUER

Les règles de ton projet.

Joue à deux sur le même appareil. Choisis un personnage puis une case libre. À ton tour, sélectionne aussi un pion déjà posé pour attaquer ou lancer un sort. Les deux équipes de démonstration permettent de commencer tout de suite.

Les contrôleurs Python, les règles de combat, les conditions de victoire, les requêtes et les templates sont ceux du projet universitaire. Le schéma SQL du dépôt étant vide, un catalogue de personnages, deux équipes et une configuration de démonstration ont été ajoutés pour essayer le jeu.

L’application d’origine utilise PostgreSQL et le serveur pédagogique BDW. Ici, un adaptateur exécute le Python avec une base SQLite locale et traduit les requêtes nécessaires. La session est remise à zéro quand tu recharges la page.
