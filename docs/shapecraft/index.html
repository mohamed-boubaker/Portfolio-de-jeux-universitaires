SHAPECRAFT
LE MOTEUR JAVA ET L’INTERFACE SWING

Construis ta chaîne.

Installe des mines et des machines, relie les tapis et transforme les formes.

Le premier lancement télécharge l’environnement Java. Jeu conseillé sur ordinateur, à la souris.

Prêt au lancement.
COMMENT JOUER

De la mine à la livraison.

Choisis une machine dans la barre d’outils. Clique pour la placer, glisse pour tracer des tapis, utilise R pour pivoter et le clic droit pour supprimer. Commence par une mine sur un gisement en bas du plateau et relie-la au centre de livraison.

Le modèle Java d’origine est conservé : mines, tapis, tunnels, rotation, découpe, peinture, mélange et empilage. L’interface Swing utilise les sprites du dépôt ; les dimensions et le chargement des images ont été adaptés à la page.

L’exécution Java dans le navigateur utilise CheerpJ. La partie reste locale à l’onglet.
